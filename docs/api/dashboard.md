title: Dashboard and Home
summary: Company health summary and home feed with suggestions
---

Two endpoints provide situational awareness for a company: the lightweight `/dashboard` for agent use, and the richer `/home` for the board UI.

## Dashboard (Agent-Friendly)

```
GET /api/companies/{companyId}/dashboard
```

Returns a health summary suitable for agent use at the start of a heartbeat:

- **Agent counts** by status (`active`, `idle`, `running`, `error`, `paused`)
- **Task counts** by status (`backlog`, `todo`, `in_progress`, `blocked`, `done`)
- **Stale tasks** — tasks `in_progress` with no recent activity
- **Cost summary** — current month spend vs budget

## Home (Board UI)

```
GET /api/companies/{companyId}/home
```

Richer endpoint used by the board Home page. On every call it runs the suggestion engine (`runAllDetectors`) synchronously before building the response. Suggestion detection failures are logged and swallowed — the home response still returns.

Returns everything in `/dashboard` plus:

- **Suggestions** — pending suggestions generated by the suggestion engine (8 categories: goal gaps, pipeline bottlenecks, memory gaps, patterns, budget optimization, recurring work, risk flags, workload balance)
- **Inbox count** — unread notifications for the requesting user
- **Recent activity** — latest mutations across the company
- **Commander reminders** — pending internal agent reminders for the user
