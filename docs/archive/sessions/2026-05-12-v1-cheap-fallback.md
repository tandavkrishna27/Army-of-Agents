# feat/v1-cheap-fallback Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a lightweight cheap-model fallback to Commander (D4): when any regular agent's monthly spend reaches 80% of its budget, auto-swap the model to the company-configured `cheap_model` for that run.

**Architecture:** A single nullable `cheap_model` column on `internal_agent_config` stores the company-wide fallback model ID. A pure `decideCheapFallback()` function (zero DB calls) encapsulates the 80%-threshold decision. A DB-backed `resolveCheapFallbackModel()` queries `cost_events` for the agent's current-month spend and the company's `cheap_model`, then calls the pure function. `heartbeat.ts` calls it in the pre-spawn window (after `runScopedConfig` is built, before `adapter.execute`) and overwrites `runScopedConfig.model` when active. The UI exposes the cheap model as an optional text field in the Commander settings Budget tab.

**Tech Stack:** Drizzle ORM | Vitest (unit + embedded-postgres integration) | React + TanStack Query | Zod validators | `pnpm db:generate` (migration only)

**Integration branch:** `v1-upgrade` (sub-branch PRs merge here, not mainline)

**Migration slot:** `0090_*` — migration ordering gate: 0088 (D8) and 0089 (D9) must already be in `v1-upgrade` HEAD before `pnpm db:generate` is run.

```ts
import { and, eq, gt, sql } from "drizzle-orm";
import type { Db } from "@armyofagents/db";
import { costEvents, internalAgentConfig } from "@armyofagents/db";

export interface CheapFallbackDecision {
  active: boolean;
  effectiveModel: string | null;
}

/**
 * Pure decision — no DB I/O.
 * Returns active=true and effectiveModel when spend/budget ≥ 0.80 and cheapModel is set.
 */
export function decideCheapFallback(
  budgetMonthlyCents: number,
  currentMonthCents: number,
  cheapModel: string | null | undefined,
): CheapFallbackDecision {
  if (!cheapModel || budgetMonthlyCents <= 0) {
    return { active: false, effectiveModel: null };
  }
  const active = currentMonthCents / budgetMonthlyCents >= 0.8;
  return { active, effectiveModel: active ? cheapModel : null };
}

/**
 * DB-backed resolver called from heartbeat.ts pre-spawn.
 * Returns the cheap model string if the fallback should activate for this agent run,
 * or null if budget is unset, cheapModel is unset, or spend is below 80%.
 */
export async function resolveCheapFallbackModel(
  db: Db,
  companyId: string,
  agentId: string,
  budgetMonthlyCents: number,
): Promise<string | null> {
  if (budgetMonthlyCents <= 0) return null;

  const [configRow] = await db
    .select({ cheapModel: internalAgentConfig.cheapModel })
    .from(internalAgentConfig)
    .where(eq(internalAgentConfig.companyId, companyId));

  const cheapModel = configRow?.cheapModel ?? null;
  if (!cheapModel) return null;

  const monthStart = new Date();
  monthStart.setDate(1);
  monthStart.setHours(0, 0, 0, 0);

  const [result] = await db
    .select({ total: sql<number>`coalesce(sum(${costEvents.costCents}), 0)` })
    .from(costEvents)
    .where(
      and(
        eq(costEvents.agentId, agentId),
        gt(costEvents.occurredAt, monthStart),
      ),
    );

  const { effectiveModel } = decideCheapFallback(
    budgetMonthlyCents,
    Number(result?.total ?? 0),
    cheapModel,
  );
  return effectiveModel;
}
```
