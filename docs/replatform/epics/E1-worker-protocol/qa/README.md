# E1 QA Results

Each QA campaign creates an immutable `<YYYY-MM-DD>-<lane>-<scope>-<sha12>-a<attempt>.md`. E1 requires package, transport/control/error, and frozen-v1 baseline evidence at its completion revision. The initial v1 record is `baseline_established`; only a later protocol change may call the non-identical frozen baseline a prior consumer.
