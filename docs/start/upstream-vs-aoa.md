title: "Upstream lineage and AoA"
summary: "How AoA evolved and where its current contracts live"
---

AoA (Army of Agents) began as a fork of an upstream agent orchestration project. Its heartbeat execution and task checkout model formed the starting point. AoA now includes the Hybrid Workforce control room, Discussion, Commander, Memory, Artifacts, Workspaces, RBAC, and an in-server MCP API.

For the current product behavior, read [the architecture overview](architecture.md), [wire contracts](../architecture/wire-compat.md), and [architecture decisions](../architecture/decisions.md). Earlier porting records remain in `docs/archive/` as historical context.
