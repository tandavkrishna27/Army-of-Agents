## Fixture contract and acceptance

The E1.1 implementation supplies accessible names `Pin panel`, `Maximize panel`, `Minimize panel`, `Close panel`, labelled panel roots and stable `data-panel-key`/`data-panel-generation` diagnostics. E2.4 supplies the real task entry routes. A representative Playwright assertion is:

```ts
const panel = page.getByRole('region', { name: 'Launch design' });
await panel.getByRole('button', { name: 'Minimize panel', exact: true }).click();
await expect(panel).toBeHidden();
await page.getByRole('button', { name: /Open panels/ }).click();
await page.getByRole('button', { name: 'Restore Launch design', exact: true }).click();
await expect(panel).toBeVisible();
```

Use the actual test seed's task title if it differs; no special application code recognizes these demo labels. `tests/e2e/universe-states.spec.ts` uses the existing E2E boot/login/company fixtures, with DB boot failures reported rather than bypassed. Run `pnpm exec playwright test --config=tests/e2e/playwright.config.ts tests/e2e/universe-states.spec.ts` only at implementation time.

Review only material experience changes with TK. Straightforward restoration of accepted controls is not a new product decision. Rollback hides the new Universe entry but preserves canonical work and state. This plan's qualification cases remain unrun until the host exists.
