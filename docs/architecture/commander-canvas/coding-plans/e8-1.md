**First-batch implementation overlay:** [Scope, implemented bindings and qualification status](../first-canvas-batch-results.md). Only the pure preferences producer and generic Canvas/controller/frame are in this batch; later storage, public routes and feature consumers remain open.

**Tech Stack:** Existing TypeScript/Zod, React, Express, PostgreSQL/Drizzle and Vitest/Playwright. No new preference library or provider SDK.

```ts
export interface UniversePreferences {
  theme: "inherit" | "system" | "light" | "dark";
  density: "comfortable" | "compact";
  motion: "subtle" | "full" | "reduced";
  dockPlacement: "top";
  dockHiding: "always" | "auto_hide";
  commanderPlacement: "automatic" | "manual";
  conversationPresentation: "compact" | "expanded";
  blobVisibility: "shown" | "hidden";
  chatVisibility: "shown" | "tucked";
  captions: "visible" | "hidden";
  captionSize: "standard" | "large";
  captionPlacement: "bottom_center" | "below_blob";
  restoreWorkspace: "previous" | "overview";
  openPanelPreviews: "auto" | "always" | "hidden";
  attentionPreviews: "auto" | "always" | "hidden";
  accent: "brand_red" | "teal" | "indigo" | "amber";
  blobStyle: "fluid" | "orbital_rings" | "minimal_glow";
  blobColor: "match_accent" | "brand_red" | "teal" | "indigo" | "amber";
  grid: "dots" | "lines" | "none";
  gridIntensity: number;
  snapToGrid: boolean;
  arrangement: "assisted" | "manual";
  voiceConnectionId: string | null;
  voiceId: string | null;
  language: string | null;
  spokenLength: "inherit" | "brief" | "balanced" | "detailed";
  personalVoiceInstructions: string;
  soundEffects: boolean;
  spokenAnnouncements: "inherit" | "quieter";
  browserViewQuality: "auto" | "reduced_bandwidth" | "high";
}
export type UniversePreferenceOverrides = Partial<UniversePreferences>;
export type PreferenceSection = "appearance" | "workspace" | "voice" | "browser";
export interface UniversePreferencesSnapshot {
  schemaVersion: 1;
  revision: number;
  overrides: UniversePreferenceOverrides;
  effective: UniversePreferences;
  unavailableFields: Partial<Record<keyof UniversePreferences, string>>;
}
export const DEFAULT_UNIVERSE_PREFERENCES: UniversePreferences = {
  theme: "inherit", density: "comfortable", motion: "subtle",
  dockPlacement: "top", dockHiding: "always", commanderPlacement: "automatic",
  conversationPresentation: "compact", blobVisibility: "shown", chatVisibility: "shown",
  captions: "visible", captionSize: "standard", captionPlacement: "bottom_center",
  restoreWorkspace: "previous", openPanelPreviews: "auto", attentionPreviews: "auto",
  accent: "brand_red", blobStyle: "fluid", blobColor: "match_accent",
  grid: "dots", gridIntensity: 0.15, snapToGrid: false, arrangement: "assisted",
  voiceConnectionId: null, voiceId: null, language: null, spokenLength: "inherit",
  personalVoiceInstructions: "", soundEffects: false, spokenAnnouncements: "inherit",
  browserViewQuality: "auto",
};
export function resolveUniversePreferences(
  overrides: UniversePreferenceOverrides,
): UniversePreferences {
  return { ...DEFAULT_UNIVERSE_PREFERENCES, ...overrides };
}
```

`resolveUniversePreferences` merges validated values only. It does not prove capability availability or authorization. Nullable provider/voice/language represent inheritance; do not silently select another provider when an explicit choice is revoked. The API populates `unavailableFields` from an authorized read-only capability catalog. E3 owns that catalog binding; until qualified, use “Not configured/Not yet validated” and disable connection controls. An absent catalog is not a healthy catalog.

**Validation/API:** Export `universePreferencesSchema` (all fields, strict), `universePreferencePatchSchema` (strict `{schemaVersion: literal(1), baseRevision: nonnegative integer, patch: universePreferencesSchema.partial().strict()}`), `universePreferenceResetSchema` (strict `{baseRevision, section: enum}`), and inferred input types. Reject unknown fields and an empty patch with 400. Connection IDs must be UUIDs; voice/language strings ≤100 characters and instructions ≤2,000 characters; instructions remain plain text. `gridIntensity` is finite 0–0.30, proposed contrast-qualified bound, default 0.15; no per-user grid-spacing preference is introduced. If qualification changes these proposed tokens/bounds, update this producer and every consumer test together before acceptance.

Export the inferred names `UniversePreferencePatchInput = z.infer<typeof universePreferencePatchSchema>` and `UniversePreferenceResetInput = z.infer<typeof universePreferenceResetSchema>`. Export `UNIVERSE_PREFERENCE_SECTIONS: Record<PreferenceSection, readonly (keyof UniversePreferences)[]>` with exactly the section membership enumerated under E8.1/2; both reset service and exhaustive UI field map import it. Tests assert every preference key belongs to exactly one section and reset drops those keys only.

Service export `universePreferencesService(db)` has `get(companyId,userId): Promise<UniversePreferencesSnapshot>`, `patch(companyId,userId,input:UniversePreferencePatchInput): Promise<UniversePreferencesSnapshot>`, `reset(companyId,userId,input:UniversePreferenceResetInput): Promise<UniversePreferencesSnapshot>`. Actor identity comes only from the authenticated request, never the body. New routes:

| Method/path under `/api` | Semantics |
|---|---|
| GET `/companies/:companyId/universe/preferences/me` | Authorized read; absent row returns revision 0 and defaults; no implicit write |
| PATCH same | Company access + board user; lock scoped row, CAS `baseRevision`, validate policy, patch named fields; 409 gives latest permitted snapshot |
| POST same plus `/reset` | CAS, clear only section's override keys, increment revision; return inherited effective values |

The UI client exports `universePreferencesApi.get/patch/reset` matching those arguments. `useUniversePreferences(companyId)` returns `{snapshot,status,error,patch,reset}` where `status` is `loading|ready|saving|unsaved|conflict|denied`. Query/cache identity includes authenticated user + company; abort and purge on either switch. Pending edits stay separate from acknowledged snapshot; 409 retains both for per-field reapply, never silently overwrites. Unknown future schema versions show safe defaults and read-only “Preferences need a newer app”; retain raw server row, disallow downgrade writes.

**Database contract:** `universe_preferences` stores UUID `id`, company UUID FK, user text FK, integer `schema_version` default 1, integer `revision` default 1, JSONB `overrides`, timestamps; unique `(company_id,user_id)`. No conversation ID, audio hardware ID, provider key, runtime prompt, layout or draft contents. Absent-row first write inserts an empty row with revision explicitly set to 0 (overriding the column default) using onConflictDoNothing, then locks and compares baseRevision before applying the patch and setting revision 1 in the same transaction. Two revision-0 writers yield one accepted and one 409; do not insert revision 1 and immediately compare it to base 0. On successful mutation call existing pinned `insertActivityLog(tx,input)` from `server/src/services/activity-log.ts` inside the same transaction with changed key names only (no instruction text); call its existing `publishActivityLogged(persisted)` only after commit. This source-verified split avoids both missing audit and pre-commit UI events.
