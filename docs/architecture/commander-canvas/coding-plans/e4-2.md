**Files:** Create `packages/shared/src/validators/universe-formats.ts`, `server/src/services/universe-format-registry.ts`, `server/src/__tests__/universe-format-matrix.test.ts`; modify shared exports and `ui/src/components/viewers/viewer-registry.ts`; create `ui/src/components/universe/ArtifactPanel.tsx`.
```ts
export type FormatDisposition = "native" | "converted" | "source_only" | "download_only";
export interface FormatCapability {
  id: string; version: number; extensions: readonly string[];
  preview: FormatDisposition;
  extraction: "text" | "structured" | "provider_gated" | "none";
  nativeExport: "qualified_writer" | "original_only";
  processorId: string | null; processorBuild: string | null;
  maxInputBytes: number; limitations: readonly string[];
}
export type FormatFailure = "unsupported" | "locked" | "damaged" | "too_large"
  | "codec_unavailable" | "font_substitution" | "resource_limit" | "denied";
```

Registry schema rejects unknown keys and executable config. File extension is a routing hint; sniffed content and parser acceptance decide activation. Unknown general uploads may be safely downloadable without preview; executable code never runs automatically. `nativeExport` refers to qualified writers in E4.3, not viewer success.

## Qualification protocol and completion

Input packet for each processor: pinned source revision, container digest/library version/license record, CPU/OS/font/codec inventory, fixture SHA-256 manifest, exact admission limits, network policy, supported native outputs. Method: run valid/malformed/locked/bomb/external-resource fixture at limit−1/limit/limit+1; record exit/status, peak RSS/CPU/disk, duration, attempted network, page/sheet/frame counts; compare rendered screenshots against fixture references and reopen any generated native output. Kill worker mid-write and revoke source mid-read; retries must preserve original and publish at most one derivative. Real isolated Linux worker plus local/cloud storage evidence required; source inspection and sanitized HTML unit tests cannot close this gate. Owners: platform containment, format engineer, design/accessibility reviewer, all unassigned.

Acceptance evidence must distinguish “native preview works”, “text extraction works”, “native writer reopens”, “download only” per family. No blanket “all formats supported”. Any changed build/font/codec invalidates affected row evidence. Gate failure keeps processor unavailable; independent safe viewers and download still work, but V1 release cannot be declared complete without the accepted family dispositions and connected failures verified.
