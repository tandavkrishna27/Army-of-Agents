```ts
export type ChatView='compact'|'expanded'|'maximized'|'tucked';
export type Presentation={chat:ChatView;lastVisible:Exclude<ChatView,'tucked'>;
  blob:boolean;captions:boolean;chatFrontmost:boolean};
export function toggleTrayChat(s:Presentation):Presentation {
  if(s.chat==='tucked') return {...s,chat:s.lastVisible,chatFrontmost:true};
  if(!s.chatFrontmost) return {...s,chatFrontmost:true};
  return {...s,lastVisible:s.chat,chat:'tucked',chatFrontmost:false};
}
export function compactChat(s:Presentation):Presentation {
  return {...s,chat:'compact',lastVisible:'compact',chatFrontmost:true};
}
```

Normal/expanded geometry is separately stored from maximized projection. `compactChat` returns to bottom docking geometry rather than retaining top/left maximized coordinates. This local function never issues microphone/session operations. E3.2 owns Start/End/Mute/Speaker commands.

## E1.5/1 — Compact, expanded, maximized and tucked chat

- [ ] Bind one E1.3 Commander destination draft to all views. First-use defaults: compact chat input and visible blob, expanded top tray. Saved preferences override first-use choices. Opening the blob does not grant audio capture.
- [ ] Compact renders Add/input/voice-symbol/Send in one aligned row, with only Expand on hover/focus. Expanded renders history with fixed composer and header Tuck, Maximize/Restore, Compact rightmost. Maximize projects usable workspace; restore returns prior expanded geometry; Compact always returns bottom dock.
- [ ] Drag/resize expanded chat using the shared E1.1 geometry mechanism without scaling text; never drag inputs. Tuck preserves draft/history and restores through the same Commander tray icon. No broken return-to-bottom button or duplicate compact/tuck icons.
- [ ] Reuse existing message/output-reference rendering and history paging rather than mounting a second execution-capable InternalAgentPanel. Capture submission context at Send, not when streaming finishes. Scroll history internally; do not force-scroll a user reading older messages. Show a new-message affordance instead.

## E1.5/2 — Blob and caption independence

- [ ] Render the layered, gently breathing AoA blob with no rectangular hover background. Keep a single straight row of small controls below it on hover/focus/tap. Stable hit targets remain readable when blob size changes; resize affordance appears at edges instead of a permanent glyph.
- [ ] Visibility controls update presentation only. Start/End voice buttons call the E3.2 port; while that port is unconfigured show a truthful unavailable state without faking a connection. Ending voice leaves the blob visible.
- [ ] Render latest caption above compact chat, or bottom-center when tucked. `captions=false` hides only captions. Below-blob preference falls back to bottom-center if blob is hidden. Expanded/maximized history receives the same live utterance so no duplicate outside overlay appears. Captions are selectable; only the small Expand control opens history.
- [ ] Panel errors, placement refusals and mic state never replace caption text. Mic/speaker state can show small icon indicators; no permanent demo status text. Do not store raw audio or partial captions in layout state.

## E1.5/3 — Shared controls, focus and restoration

- [ ] Wire the tray primary click using `toggleTrayChat`, menu visibility using separate booleans and compact/maximize using explicit actions. Composer voice symbol starts voice when disconnected; when already connected it reveals blob/controls without opening another session.
- [ ] On hide/tuck return focus to an accessible tray control. The path from compact chat to Expand remains hittable while pointer crosses it; use one focus-within/hover boundary rather than independently disappearing nodes.
- [ ] Apply E8.1 `chatVisibility`, `blobVisibility`, `captions`, `captionPlacement`, `conversationPresentation`, `motion`, `blobStyle` and color preferences. Geometry stays per-conversation, preferences per user/company. Changing company cancels stale fetch/stream subscription rendering before restoring the new scope.

```ts
it('tray toggle preserves blob and captions',()=>{
  const s:Presentation={chat:'compact',lastVisible:'compact',blob:true,captions:true,chatFrontmost:true};
  expect(toggleTrayChat(s)).toEqual({...s,chat:'tucked',chatFrontmost:false});
  expect(toggleTrayChat(toggleTrayChat(s))).toEqual(s);
});
it('compact exits maximized state',()=>{
  const s:Presentation={chat:'maximized',lastVisible:'expanded',blob:false,captions:true,chatFrontmost:true};
  expect(compactChat(s).chat).toBe('compact');
  expect(compactChat(s).blob).toBe(false);
});
```
