## Reproduced defects and fixes

1. Resizing supplied negative dimensions because controlled node projections discarded React Flow measurements. Preserving measured dimensions separately fixed all eight handles; browser regression failed before the fix and passed after it.
2. A renderer function executed above its boundary and could remove the workspace. Invocation now occurs beneath the panel boundary; failure/retry is browser-verified.
3. Lost pointer capture removed neither the shield nor the underlying mouse gesture correctly. The cancellation regression now verifies that subsequent Close works.
4. Hiding the host at zero size unmounted drafts/iframe state. Last valid layout bounds preserve mounted content; hide/show regression verifies both draft and iframe input state.
5. Opening a task from an artwork source link was followed by a parent click handler reselecting the artwork. The original panel then covered the task controls. Selection now runs at capture time; the conflicting bubble handler was removed. Source-link → task → Close → focus-return is verified. This reproduces the failure pattern in the new adapter; it does not certify the old mock or future real task route fixed.
