# Support

Use the channel that matches the request.

## Questions and usage help

For setup questions, docs issues, or usage problems:

- Check the public docs at https://docs.armyofagents.org.
- Search existing GitHub issues.
- Open a new issue with your environment, command, expected behavior, and actual behavior.

## Bug reports

Open a bug report issue when the problem is not security-sensitive. Include reproduction steps, logs with secrets removed, and the affected version or commit.

## Feature requests

Open a feature request issue with the problem, proposed solution, alternatives considered, and expected impact.

## Security reports

Do not use public issues for vulnerabilities. Follow [`SECURITY.md`](SECURITY.md).

## Commercial or roadmap discussions

Use https://armyofagents.org for project and product information. Public roadmap items that are not shipped should stay clearly labeled as planned work.
